# Status and Assessments

本目录保存状态报告、审计报告、成熟度评估和知识图谱。它是 status 类文档的唯一入口。

状态报告不放在 `docs/archive/` 下。即使报告本身是历史快照，也应该留在这里，便于比较项目成熟度、审计结果和阶段性变化。

## Usage

- 用当前未解决问题(生产成熟度、CI、安全、迁移链、E2E 等)时，先看 [issues/README.md](../issues/README.md)。
- 用 agent 模块结构、问题清单和改进方向时，先看 issues/ 下最新的 agents module review report。
- 用历史对比时，按日期倒序阅读。
