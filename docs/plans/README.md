# Plans

本目录是计划文档的唯一入口。

## 目录约定

| 目录 | 用途 |
|---|---|
| `active/` | 当前仍在执行，或仍作为目标状态依据的计划 |
| `archive/` | 已完成、被替代、暂停或仅供历史追溯的计划 |
| `archive/superpowers/` | 历史 agent 执行计划、迁移计划和审计计划 |

不再使用 `docs/archive/plans/`。所有计划都应该放在本目录下，避免 archive 与 plans 双重归档。
